이 컴퓨터(브라우저)에 깔린 한국어 목소리를 빌려 써요. 무료지만 MP4로 내보내면 대사 소리가 들어가지 않아요. 문구·타이밍 확인용이에요.
⚠️ 이 브라우저에는 한국어 남자 목소리가 없어요 그래서 남성·할아버지·남자아이를 골라도 모두 같은 여자 목소리로 나와요. 해결 방법: ① Microsoft Edge(엣지)로 이 페이지를 열기 → 무료 한국어 남자 목소리(InJoon 등)가 생겨요 (내 PC 파일이면 파일 오른쪽 클릭 → 연결 프로그램 → Microsoft Edge) ② 위에서 ElevenLabs나 Typecast를 고르기 → 12가지 목소리가 모두 달라지고, MP4에도 소리가 들어가요
목소리상태선택

⚠ 상업 이용 안내 · 가게·회사 홍보영상은 상업 이용이라 두 서비스 모두 유료 요금제가 필요해요. 무료 요금제로 만든 음성은 상업적으로 쓸 수 없고, 개인 용도로 올릴 때도 출처 표기(ElevenLabs: 제목에 elevenlabs.io / Typecast: 타입캐스트 사용 문구·캐릭터 이름·사이트 주소)가 필요해요. 요금과 조건은 각 서비스 사이트에서 최신 내용을 확인해 주세요. API 키는 이 컴퓨터의 브라우저에만 저장되니, 여러 사람이 함께 쓰는 컴퓨터에서는 사용 후 키를 지워주세요.
